# Revenue Monster Objects And Codes

Transaction Object, nested objects, enums, payment method names, and FPX bank codes. Checked 2026-10-21.

Sources:

- `https://doc.revenuemonster.my/docs/v2/payment/query-transaction` (Transaction Object, nested objects, Type, Status, Method & Region)
- `https://doc.revenuemonster.my/docs/payment-method` (system method names)
- `https://doc.revenuemonster.my/docs/bank-code` (FPX B2C and B2B codes)
- `https://doc.revenuemonster.my/docs/v2/payment/online-payment` (`GET /v3/payment/fpx-bank` example)
- `https://doc.revenuemonster.my/docs/product-terms` (ID terms)

## IDs

| ID | Generated by | Notes |
| --- | --- | --- |
| `orderId` / `order.id` | You (merchant) | Max 24 chars, unique per attempt. |
| `transactionId` | RM server | Store it; used for refund and query. |
| `referenceId` | Wallet / payment provider | Provider reference. |
| `checkoutId` | RM | Checkout session, not a transaction. |

Always store either `transactionId` or `order.id` for querying.

## Transaction Object

Returned as `item` by query, refund, reverse, quick pay, terminal, and customer order calls.

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `store` | Store object | No | See Store. |
| `referenceId` | String | No | Provider reference. |
| `transactionId` | String | Yes | RM transaction ID. |
| `terminalId` | String | No | Terminal ID. |
| `currencyType` | String | Yes | `MYR` only. |
| `balanceAmount` | Uint64 | Yes | Remaining refundable amount (sen). |
| `finalAmount` | Uint64 | Yes | Amount after voucher and membership deductions (sen). |
| `platform` | String | Yes | `TERMINAL`, `MOBILE_APP`, `OPEN_API`, `WEB_LOYALTY`. |
| `type` | String | Yes | See Transaction Type. |
| `method` | String | Yes | Method without region suffix, for example `FPX`, `GOBIZ`, `TNG`. |
| `region` | String | Yes | For example `MALAYSIA`. |
| `status` | String | Yes | See Transaction Status. |
| `source` | String | Yes | Internal: `RECURRING`, `ALACARTE` (empty string in the example). |
| `transactionAt` | RFC3339 | No | Only when `SUCCESS`. |
| `createdAt`, `updatedAt` | RFC3339 | Yes | |
| `error.message` | String | No | Only when failed. |
| `payee.userId`, `payee.subUserId` | String | No | Provider user IDs. |
| `order.id` | String | Yes | |
| `order.title` | String | Yes | Max 32. |
| `order.currencyType` | String | Yes | `MYR`. |
| `order.amount` | Uint64 | Yes | Sen. |
| `order.detail` | String | No | Max 600. |
| `order.additionalData` | String | No | Max 128. |
| `voucher.key` | String | No | Internal. |
| `voucher.discountAmount` | Uint64 | No | Total voucher discount. |
| `voucher.wallet` | Payment Provider Discount Info | No | |
| `voucher.membership` | Membership Discount Info | No | |
| `extendInfo.buyNowPayLater` | BNPL object | No | |
| `extendInfo.inHousePromo` | In House Promotion | No | Internal. |
| `extendInfo.duitnowInfo` | DuitNow Info | No | |
| `extraInfo.card` | Card Payment | No | |
| `extraInfo.onlineBanking` | Online Banking (FPX) | No | |
| `extraInfo.loyalty` | Spending Loyalty | No | Present for QRCODE-mode loyalty payments. |

Example (official, sandbox): `{"referenceId":"230522162302AC0570UM","transactionId":"230522082259300426500551","order":{"id":"1684743768790895","title":"Demo","detail":"Demo","additionalData":"Demo","amount":120},"terminalId":"","payee":{"userId":"","subUserId":""},"currencyType":"MYR","balanceAmount":120,"finalAmount":120,"voucher":null,"platform":"OPEN_API","method":"GOBIZ","transactionAt":"2023-05-22T08:23:02Z","type":"WEB_PAYMENT","status":"SUCCESS","region":"MALAYSIA","source":"","createdAt":"2023-05-22T08:23:02Z","updatedAt":"2023-05-22T08:23:11Z"}`

### Store

`id` (required), `name`, `imageUrl`, `addressLine1`, `addressLine2`, `postCode`, `city`, `state`, `country`, `countryCode` (phone country code), `phoneNumber`, `geoLocation.latitude`, `geoLocation.longitude` (Float64), `status` (for example `ACTIVE`), `createdAt`, `updatedAt` (RFC3339).

### BuyNowPayLater (BNPL)

| Field | Type | Notes |
| --- | --- | --- |
| `isBuyNowPayLater` | bool | BNPL transaction flag. |
| `installmentMonth` | Uint64 | Months selected. |

### Online Banking (FPX)

| Field | Type | Notes |
| --- | --- | --- |
| `buyerName` | String | FPX buyer name. |
| `bankId` | String | FPX bank ID, for example `TEST0021` in sandbox. |
| `bankName` | String | For example `SBI Bank A` in sandbox. |
| `bankReferenceId` | String | FPX bank reference number. |
| `type` | String | `B2C` or `B2B`. |

### DuitNow Info

| Field | Type | Notes |
| --- | --- | --- |
| `paymentMethod` | String | For example `TNG`. |
| `referenceId` | String | DuitNow reference. |
| `payerName` | String | Payer name. |

### Card Payment

| Field | Type | Notes |
| --- | --- | --- |
| `cardType.brand`, `cardType.type`, `cardType.issuer` | String | For example `VISA`, `CREDIT`. |
| `cardType.alpha2`, `cardType.alpha3` | String | ISO3166 card country. |
| `cardType.country` | String | Country name. |
| `provider` | String | Internal: `SC`, `GOBIZ`, `PAYDEE`. |
| `isTokenization` | bool | Paid with token vs PAN. |
| `token` | String | Token used. |
| `maskNo` | String | Masked PAN, for example `XXXX-XXXX-XXXX-2354`. |
| `inputType` | String | `MAG`, `IC`, `NFC` (terminal). |
| `referenceId` | String | Card reference number. |
| `secondaryReferenceId` | String | Card invoice number. |
| `domain` | String | Online card payment domain. |

### Spending Loyalty

`id`, `code`, `qrcode` (QR content to print on the receipt so the customer can claim points).

### Payment Provider Discount Info (`voucher.wallet`)

`salesAmount`, `discountAmount`, `grossAmount` (Uint64, sen; gross = sales minus discount).

### Membership Discount Info (`voucher.membership`)

`memberId`, `voucherId`, `discountAmount` (Uint64).

### In House Promotion (internal)

`amount`, `info[].label`, `info[].uniqueID`, `info[].source`, `info[].amount`.

## Transaction Type

| Value | Meaning |
| --- | --- |
| `QUICK_PAY` | Quick Pay (merchant scans customer code). |
| `RETAIL_QRPAY` | Coming soon: offline Retail QR. |
| `BANK_CARD` | Terminal card transaction. |
| `WEB_PAYMENT` | Web payment checkout. |
| `WEB_MOBILE_PAYMENT` | H5 / mobile payment checkout. |
| `MINI_PROGRAM` | Mini program checkout. |
| `RECURRING_PAYMENT` | Recurring payment transaction. |
| `QR_PAY` | Deprecated. |
| `MOBILE_PAYMENT` | Deprecated, now `WEB_MOBILE_PAYMENT`. |

Note: the POS pages show `type` values `QUICKPAY` or `BANK_CARD` in terminal responses (`https://doc.revenuemonster.my/docs/pos/payment`); the Query Transaction appendix spells it `QUICK_PAY`. Accept both.

## Transaction Status

| Value | Meaning |
| --- | --- |
| `SUCCESS` | Paid. |
| `FAILED` | Failed. |
| `IN_PROCESS` | Pending. Keep querying. |
| `FULL_REFUNDED` | Fully refunded. |
| `PARTIAL_REFUNDED` | Partially refunded. |
| `REVERSED` | Reversed (RM reverses automatically on timeout). |

Checkout statuses (Query Payment Checkout, redirect): `SUCCESS`, `FAILED`, `CANCELLED`, `EXPIRED`.
